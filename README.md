# 🍳 Семейная кухня — рецепты

Меню из двух семейных рецептов-калькуляторов: вводишь базовый вес —
все ингредиенты пересчитываются в граммах.

## Рецепты

- 🍰 **Бисквит-калькулятор** (`biskvit.html`) — вес яиц на входе, рецепт «в одну чашу»
  на выходе. Опции: какао (шоколадный) и «пряный» (корица, бадьян).
- 🍚 **Узбекский плов** (`plov.html`) — вес мяса на входе. Домашняя версия по видео
  Сталика Ханкишиева (кастрюля с плоским дном, электроплита): рис = морковь = мясо,
  лук 15–19%, масло 10–15%. Переключатель «девзира / басмати» меняет шаги
  замачивания и количества воды.

## Как открыть

- Онлайн (GitHub Pages): **https://devsergeev.github.io/family-recipes/**
  - Меню: `/` · Бисквит: `/biskvit.html` · Плов: `/plov.html`
- Локально: просто открыть `index.html` двойным кликом в любом браузере.
  Никакой установки не нужно.

## Технология

Статические HTML-файлы без зависимостей: HTML + CSS + vanilla JS. Работает офлайн,
адаптировано под телефон. Тёмная и светлая темы: по умолчанию тёмная, переключатель
в правом верхнем углу, выбор запоминается (и синхронизирован между страницами).
Введённые значения (яйца, мясо, какао, специи, тип риса) тоже сохраняются
в браузере — после перезагрузки всё на месте.
